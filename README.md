# Heat Transfer Modeling in Spacecraft Materials

This project applies numerical methods to the **heat equation** to study transient heat transfer through engineering materials. The model examines how material properties, boundary conditions, and other assumptions influence temperature behavior over time.

Developed as part of **MATH 440: Mathematical Modeling** at Christopher Newport University.

## Project Overview

The project uses a finite-difference approach to approximate the heat equation computationally. By changing material properties and model conditions, the simulation can be used to compare how different materials respond to thermal loads over time.

The project includes:

- numerical approximation of a partial differential equation
- implementation of finite-difference methods in Python
- comparison of temperature evolution across materials
- investigation of material properties and boundary conditions
- visualization and interpretation of transient thermal behavior

## Mathematical Approach

The heat equation provides a mathematical description of how temperature changes through a material over space and time. A finite-difference method is used to discretize the problem so that the temperature field can be approximated numerically and evaluated under different physical assumptions.
